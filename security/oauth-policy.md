# Política de OAuth

Regra: nenhum app de terceiros no GitHub ou Google sem autorização consciente e documentada.

- Revogar em github.com/settings/applications quando não for necessário.
- Revogar em myaccount.google.com/permissions quando não for necessário.
- Preferir API pública sem token quando existir (ex: feeds CSV/JSON da abuse.ch).
- Toda autorização nova gera um registro aqui com data, app, escopo e motivo.
