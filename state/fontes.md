# Fontes validadas do Meridian

Critério: fonte primária, gratuita, com conteúdo real e acionável.

## Cyber
1. https://portswigger.net/web-security — Web Security Academy. Labs reais de XSS, CSRF, injeção. Gratuito.
2. https://exercism.org — exercícios com review humano. Dezenas de linguagens.
3. https://raw.githubusercontent.com/trimstray/the-practical-linux-hardening-guide/master/README.md — hardening Linux prático. Conteúdo versionado.
4. https://github.com/trimstray/the-practical-linux-hardening-guide — repo completo do guia.
5. https://github.com/decalage2/awesome-security-hardening — curadoria viva de hardening prático. Milhares de links.
6. https://owasp.org/www-project-top-ten/ — OWASP Top 10. Referência canônica.

## Engenharia
7. https://docs.python.org/3/ — documentação oficial Python.
8. https://developer.mozilla.org/en-US/docs/Web/JavaScript — MDN. Referência JS.

## Automação
9. https://docs.github.com/en/actions — GitHub Actions. CI/CD.
10. https://vercel.com/docs — Vercel. Deploy e runtime.

## Observação
O feed da abuse.ch (ThreatFox/URLhaus) foi removido. O OAuth dela no GitHub foi revogado em 2026-10-19. Se um dia for reintroduzir, use a API pública sem OAuth: https://threatfox.abuse.ch/export/json/recent/ e https://urlhaus.abuse.ch/downloads/csv_recent/ — não exigem token.
